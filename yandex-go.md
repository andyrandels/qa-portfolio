# Yandex Go — такси и доставка

[← К оглавлению](README.md)

Yandex Go — суперприложение для заказа такси, доставки и других сервисов. В фокусе были сценарии заказа такси: адреса, тарифы, стоимость, способы оплаты, отмена, а также поведение при плохой сети и без геолокации.

| Параметр | Значение |
| --- | --- |
| Платформы | Android 13 (Samsung Galaxy A52), iOS 17 (iPhone 12) |
| Версия | Актуальная из Google Play / App Store на дату тестирования |
| Области | Авторизация по номеру телефона, ввод адресов, тарифы, расчёт стоимости, оплата, промокоды, отмена, история поездок, доставка |
| Инструменты | Charles Proxy (анализ трафика, throttling), ADB, настройки разработчика (фиктивная геолокация) |

## Тест-кейсы

### TC-YG-001. Оформление заказа такси и отмена до назначения водителя

Приоритет: High · Предусловие: пользователь авторизован, способ оплаты — наличные, геолокация разрешена.

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть раздел «Такси» | Адрес подачи заполнен по текущему местоположению |
| 2 | Ввести адрес назначения, выбрать из подсказок | Построен маршрут, показаны тарифы со стоимостью и временем подачи |
| 3 | Выбрать тариф «Эконом» и нажать «Заказать» | Заказ создан, статус «Ищем машину» |
| 4 | Нажать «Отменить» и подтвердить | Заказ отменён без платы за отмену, в истории статус «Отменён» |

### TC-YG-002. Применение промокода (таблица решений)

Приоритет: Medium · Предусловие: открыт экран ввода промокода.

| Промокод | Срок действия | Уже использован | Ожидаемый результат |
| --- | --- | --- | --- |
| Существует | Активен | Нет | Промокод применён, скидка отображается в тарифе |
| Существует | Активен | Да | «Промокод уже использован» |
| Существует | Истёк | — | «Срок действия истёк» |
| Не существует | — | — | «Промокод не найден» |
| Валидный, с пробелом в конце | Активен | Нет | Пробел обрезается, промокод применён |

### TC-YG-003. Потеря сети при нажатии «Заказать»

Приоритет: High · Предусловие: маршрут построен, тариф выбран; в Charles Proxy настроен throttling 3G.

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Нажать «Заказать» и сразу включить авиарежим | Сообщение об отсутствии сети, кнопка неактивна или показан лоадер |
| 2 | Выключить авиарежим | Приложение показывает актуальный статус: заказ создан или не создан |
| 3 | Открыть историю заказов | Не более одного активного заказа, дублей нет |

## Баг-репорты

<a id="bug-yg-01"></a>
### BUG-YG-01. Промокод с пробелом в конце отклоняется как несуществующий

| Поле | Значение |
| --- | --- |
| Severity / Priority | Minor / Medium |
| Окружение | Samsung Galaxy A52, Android 13; iPhone 12, iOS 17 |
| Предусловие | Есть активный неиспользованный промокод |
| Шаги | 1. Скопировать промокод из SMS вместе с пробелом после него. 2. Вставить в поле «Промокод». 3. Нажать «Применить». |
| Фактический результат | «Промокод не найден» |
| Ожидаемый результат | Пробелы по краям обрезаются, промокод применяется |
| Вложения | Скриншот ошибки, запрос из Charles с значением в кавычках |

<a id="bug-yg-02"></a>
### BUG-YG-02. При потере сети и повторном нажатии «Заказать» создаётся два заказа (Android)

| Поле | Значение |
| --- | --- |
| Severity / Priority | Critical / High |
| Окружение | Samsung Galaxy A52, Android 13; Charles Proxy, throttling 3G; на iOS не воспроизводится |
| Предусловие | Маршрут построен, тариф выбран, оплата наличными |
| Шаги | 1. Нажать «Заказать». 2. Во время загрузки отключить Wi-Fi и мобильные данные. 3. После ошибки включить сеть и нажать «Заказать» повторно. |
| Фактический результат | В истории два активных заказа на один маршрут; в Charles видны два успешных запроса создания |
| Ожидаемый результат | Приложение проверяет статус первого запроса; создаётся не более одного заказа |
| Вложения | Видео с экрана, сессия Charles (.chls), лог adb logcat |
