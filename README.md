# Портфолио QA-инженера

Примеры тестовой документации по трём проектам: веб-платформе SimpleOne (ITSM) и мобильным приложениям Яндекс Метро и Yandex Go. Для каждого проекта есть чек-листы, тест-кейсы и баг-репорты в формате, принятом в командах.

| Проект | Тип | Что внутри |
| --- | --- | --- |
| [SimpleOne](simpleone.md) | Web (B2B, ITSM) + REST API | 5 чек-листов, 6 тест-кейсов, 4 баг-репорта |
| [Яндекс Метро](yandex-metro.md) | Мобильное приложение (Android, iOS) | Чек-лист, 3 тест-кейса, 2 баг-репорта |
| [Yandex Go](yandex-go.md) | Мобильное приложение (Android, iOS) | Чек-лист, 3 тест-кейса, 2 баг-репорта |

## Навыки

- **Виды тестирования:** функциональное, регрессионное, smoke, тестирование ролевой модели, UI, API, кросс-браузерное, мобильное (Android, iOS).
- **Техники тест-дизайна:** классы эквивалентности, граничные значения, таблицы решений, переходы состояний.
- **Инструменты:** Jira, Confluence, TestIT, Postman, Chrome DevTools, Charles Proxy, Android Studio (эмулятор, ADB), Xcode Simulator, SQL (DBeaver).

## Примечание

Данные заказчиков по проекту SimpleOne обезличены (NDA), примеры построены на стандартной функциональности платформы. Мобильные приложения проверялись как пользовательские продукты на реальных устройствах и эмуляторах.
