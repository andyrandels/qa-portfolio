# Яндекс Метро — мобильное приложение

[← К оглавлению](README.md)

Яндекс Метро показывает схемы метрополитенов и строит маршруты между станциями с временем в пути и пересадками. Тестировались основные пользовательские сценарии и поведение в мобильных условиях: без сети, при прерываниях, смене ориентации.

| Параметр | Значение |
| --- | --- |
| Платформы | Android 13 (Samsung Galaxy A52), iOS 17 (iPhone 12), эмулятор Pixel 6 (Android 14) |
| Версия | Актуальная из Google Play / App Store на дату тестирования |
| Области | Схема и масштабирование, построение маршрута, поиск станций, выбор города, избранное, офлайн-режим, тёмная тема |
| Инструменты | Android Studio (эмулятор, ADB logcat), Charles Proxy (эмуляция медленной сети) |

## Тест-кейсы

### TC-YM-001. Построение маршрута с пересадкой

Приоритет: High · Предусловие: выбран город Москва, интернет подключён.

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Тапнуть по станции «Сокольники» → «Отсюда» | Станция отмечена как начало маршрута |
| 2 | Тапнуть по станции «Пушкинская» → «Сюда» | Построен маршрут, указаны время в пути, число пересадок и станция пересадки |
| 3 | Открыть детали маршрута | Список станций по порядку, цвета линий соответствуют схеме |
| 4 | Нажать «Поменять местами» | Маршрут перестроен в обратном направлении |

### TC-YM-002. Работа без интернета

Приоритет: High · Предусловие: схема города уже загружалась онлайн.

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Включить авиарежим, закрыть и снова открыть приложение | Схема отображается из кэша |
| 2 | Построить маршрут между двумя станциями | Маршрут построен без сети |
| 3 | Выключить авиарежим | Приложение работает, нет вылетов и лишних ошибок |

### TC-YM-003. Поиск станции (классы эквивалентности)

Приоритет: Medium · Предусловие: открыта строка поиска станции.

| Шаг | Ввод | Ожидаемый результат |
| --- | --- | --- |
| 1 | «Твер» (начало названия) | В выдаче «Тверская» |
| 2 | «тверская» (нижний регистр) | В выдаче «Тверская» |
| 3 | «Семеновская» (е вместо ё) | В выдаче «Семёновская» |
| 4 | «Тверская» в английской раскладке («Ndthcrfz») | Исправление раскладки или сообщение «Ничего не найдено», без вылета |
| 5 | Спецсимволы «%$#@» и строка из 100 символов | «Ничего не найдено», без вылета |

## Баг-репорты

<a id="bug-ym-01"></a>
### BUG-YM-01. Поиск не находит станцию при вводе «е» вместо «ё»

| Поле | Значение |
| --- | --- |
| Severity / Priority | Minor / Medium |
| Окружение | Samsung Galaxy A52, Android 13; iPhone 12, iOS 17 |
| Шаги | 1. Открыть поиск станции. 2. Ввести «Семеновская». |
| Фактический результат | «Ничего не найдено» |
| Ожидаемый результат | В выдаче «Семёновская»: «е» и «ё» считаются эквивалентными |
| Вложения | Скриншоты с обоих устройств |

<a id="bug-ym-02"></a>
### BUG-YM-02. Построенный маршрут сбрасывается при повороте экрана (Android)

| Поле | Значение |
| --- | --- |
| Severity / Priority | Major / Medium |
| Окружение | Samsung Galaxy A52, Android 13; воспроизводится на эмуляторе Pixel 6, Android 14; на iOS не воспроизводится |
| Предусловие | Автоповорот экрана включён |
| Шаги | 1. Построить маршрут между двумя станциями. 2. Повернуть устройство в горизонтальное положение. |
| Фактический результат | Маршрут и выбранные станции сбрасываются, отображается пустая схема |
| Ожидаемый результат | Маршрут сохраняется, схема перестраивается под новую ориентацию |
| Вложения | Видео с экрана, лог adb logcat |
